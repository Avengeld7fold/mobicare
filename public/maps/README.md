# MobiCare Light

Local adaptation of OpenFreeMap Liberty: https://tiles.openfreemap.org/styles/liberty
Style source: https://github.com/hyperknot/openfreemap-styles (MIT repository; Liberty code BSD-3-Clause, design CC BY 4.0). Full upstream notices are in LICENSE.md.
Sprite assets: OpenFreeMap's published ofm sprite using Maki POI icons (CC0).
Map data: © OpenStreetMap contributors / OpenMapTiles. Attribution is displayed by Leaflet.

Light flat buildings, pale blue water, cream arterial roads, restrained POIs from zoom 16.
This is an independently styled OpenStreetMap map, not Google Maps data or tiles.
The public OpenFreeMap service requires no API key but offers no uptime SLA.

`worker/` is generated from the installed MapLibre version by predev/prebuild.
Do not edit those generated files. MapLibre includes its BSD license notice.
